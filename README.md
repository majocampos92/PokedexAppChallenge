# Pokedex App Challenge

### Aplicación iOS desarrollada en Swift que muestra una lista de Pokémon consumiendo la API pública de PokéAPI.
---

## Requisitos

Antes de correr el proyecto, asegúrate de tener instalado:

- Xcode 15.6+
- Swift 5+
- CocoaPods
- macOS

---

## Instalación

Sigue estos pasos para configurar el proyecto localmente:

Clonar el repositorio
```bash
git clone https://github.com/majocampos92/PokedexAppChallenge.git
cd pokedex-app
```

Instalar Dependencias 
```bash 
pod install
```

Abrir el proyecto: IMPORTANTE usar .xcworkspace
```bash
open PokedexAppChallenge.xcworkspace
```
